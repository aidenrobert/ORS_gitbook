# ORS_gitbook

Welcome to the repository for Git exercises as part of the Open &amp; Reproducible Science course, held at Stockholm University, 2026. We will practice some basic Git commands to familiarize yourself with its use in code development. The goal is to be at a level where you can use these tools to back up, save, track the evolution of, and eventually publish the code you use in your research.

In Stage 1, you will work with this repo on your own and run the basic commands by writing and pushing a recipe to your own branch. In Stage 2, you will collaborate with others to create a recipe book file, showing you how Git can be used to collaborate, troubleshoot, and publish code together. The instructions are given in text files (e.g. 'stepX_ ... .txt') in sequential order, each step building on tools from the last.

Happy cooking 🍳!
